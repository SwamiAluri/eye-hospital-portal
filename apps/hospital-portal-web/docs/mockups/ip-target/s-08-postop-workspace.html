There is no separate post-op vitals endpoint. Recovery observations append to vital_sign through POST /api/ip-management/journeys/{id}/vitals, the same series the ward board and pre-op step write to, so the whole stay reads as one observation chart. Corrections use PATCH …/vitals/{vitalId}.
